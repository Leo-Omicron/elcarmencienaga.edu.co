# El Carmen · Ciénaga

Página inicial del sitio elcarmencienaga.edu.co, desarrollada con HTML y CSS sin dependencias externas.

## Desarrollo local

Desde la raíz del repositorio, con Python 3 instalado:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Abre el puerto 8000 en tu entorno de desarrollo. Para detener el servidor, pulsa Ctrl+C.

Edita `index.html` y recarga el navegador para ver los cambios. No se requiere compilación ni configuración de secretos.

Este servidor es para desarrollo. Para producción, publica los archivos en un alojamiento de sitios estáticos.
